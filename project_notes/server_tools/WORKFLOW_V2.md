# TCAD 工作流 v2

本工具目前限定已核验的 4E17SPICE_1.18u、八节点顺序和参数，不是任意工程的通用调度器。新器件/节点需先核验并扩展配置校验。

## 运行入口

`check` 检查环境与输入；`prepare --mode original --task-id EXP-xxx` 登记新批次并预处理，默认不复制完整工程；`--mode copy` 仅用于明确要求隔离的任务。prepare 会备份将覆盖的元数据、预处理文件和选定节点旧输出。

`submit --run-id ...` 仅提交已准备的批次；同编号重复提交不启动第二次。同实际工程锁从准备持续到结果归档完成。准备失败保留错误和备份；存在不明活动进程时不自动解除锁。

`monitor --run-id ...` 添加独立只读观察器。`status` 不提交；`collect` 获取稳定文件；`refresh` 依次回收、解析、出图和报告，网络异常时标记状态待更新。`cancel` 仅用于明确停止请求，收到请求不等于全部进程已停止。

失败停止后续节点，不自动重试、修改模型、扩大到上游/下游，或因进展缓慢杀进程。

## 证据和归档

保留任务编号、Git 版本、远端输入哈希及运行编号。Git 提交是本机工具/允许输入的版本，远端真实输入仍以 manifest 哈希为准。

原工程模式在每节点结束后把本次输出复制到批次 artifacts 并核验哈希；下次运行前先保存需要保留的旧结果。TDR 归档在服务器，GitHub 仅保存清单和图表。归档在同一服务器，不宣称具备异地灾备。

旧副本任务使用其实际 project 和冻结 agent.py，不替换正在运行的程序。查询使用新客户端也不会迁移、重启该任务。

服务器和本机可能有时钟偏差；server_utc/client_utc 分别记录，新旧结果判断使用服务器时间。stdout、stderr、退出码和命令保存在本地 results 与远端批次目录，报告提供索引。

## 监控

每 60 秒记录状态、已接受的时间/偏压、迭代摘要、进程 CPU/RSS 和剩余空间；日志增量解析保留未写完的行，截断后重建状态。15 分钟无可确认进展仅标注需检查。扫描比例不是总耗时百分比，不给出虚构 ETA。

没有主动消息通知服务。SSH/本机窗口关闭不终止服务器观察器；服务器故障可能中断它。监控错误与求解错误分开记录。

## 数据与图

仅自动解析已验证的单 Data 块 DF-ISE ASCII xyplot；多块/二进制/截断文件保留并报错。工具包的列式切片解析器未采用。

原始电流符号、单位、AreaFactor 保留。当前 Id–Vd 报告记录 10 V 电流、PPL/NOPPL 贡献、KCL 残差；不外推，不从这些数据推断 Vth/BV/热失控。

本机 Python 绘图依赖在 `.workflow_deps`，来源为此前已安装的独立绘图库，版本见 requirements-workflow.txt。曲线 PNG 300 dpi + SVG，字体 >=12 pt。SVisual 使用已安装 W-2024.09-SP1 的 -b/-bx，单线程后处理，原始 TDR 前后哈希核验。

基准节点 15/16，组内最大 RMS 差异节点、首个失败节点参与空间分析；只选本次真实输出。无 TDR、未知状态、无字段或图形导出失败均显式记录。现有最终快照不能替代未保存的中间状态。
